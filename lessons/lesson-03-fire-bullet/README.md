## 💡 生活中的小比喻：什么是“对象的生命周期”？

想象一下：如果你放烟花，烟花升空、爆炸、熄灭。如果熄灭的烟花壳永远留在天上不消失，天空中就会堆满垃圾，最终把天空堵死！

在电脑里也是一样：
1. **诞生（Born）**：坦克按下空格键，`new Bullet(...)` 创造一颗子弹加入 `bullets` 数组。
2. **存活飞行（Fly）**：在每一帧里，子弹往前飞一段距离（`x += vx, y += vy`），并在身后留下漂亮的拖尾。
3. **销毁回收（Die）**：当子弹飞出屏幕边界时，我们给它标记 `isAlive = false`，然后用 `filter()` 把它从数组中清除，释放电脑内存！

```text
 坦克开火 ──> new Bullet() ──> 加入 bullets 数组 ──> 飞出屏幕 ──> filter() 销毁回收
```

## 📐 炮口位置与发射方向的秘密

很多小朋友会问：“子弹为什么刚好从炮管尖端飞出来，而不是从坦克屁股或者肚子里飞出来？”

答案是**极坐标转换**：
- 坦克的中心是 `(tank.x, tank.y)`
- 炮管的长度是 `barrelLength`
- 炮口的真实位置就是：
```javascript
const rad = (this.angle * Math.PI) / 180; // 角度转弧度
const muzzleX = this.x + Math.sin(rad) * this.barrelLength; // 炮口 X
const muzzleY = this.y - Math.cos(rad) * this.barrelLength; // 炮口 Y
```
